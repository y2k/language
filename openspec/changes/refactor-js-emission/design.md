# Design

## Context

Мотивация — в `proposal.md`. Сейчас `backend_compiler/js.ml` собирает выражения и тела строковыми конкатенациями и `String.concat`. Это самостоятельный рефакторинг до реализации `inline-js-source-maps`; карты ещё нет.

## Goals / Non-Goals

**Goals:** компактная композиция фрагментов, однократная запись в общий буфер, побайтовое сохранение JS и публичного результата `compile`.

**Non-Goals:** source maps, source positions, scoped origin, новые CLI-параметры, изменение AST/lowering и общий framework генерации.

## Decisions

### Отложенные фрагменты

Использовать локальный тип фрагмента `(string -> unit) -> unit`: фрагмент получает функцию записи текста. Небольшие `text`, `concat`, `join` заменяют внутренние конкатенации, сохраняя структуру веток генератора. В конце `compile` фрагмент выполняется один раз с `Buffer.add_string buffer`, затем возвращается `Buffer.contents buffer`. Функции экранирования и munging могут по-прежнему возвращать строки.

Передача функции записи оставляет простой стык для последующего writer, не требуя сейчас модуля `Source_map`, координат или origin. Строковые фрагменты с таблицами смещений здесь не нужны; прямой императивный emitter во всех ветках сильнее менял бы структуру генератора.

### Сохранение вывода

Сохранять порядок обхода, выделения временных имён, пробелы, переводы строк, скобки, imports, exports и raw-code. Lowering и `Gensym` не переносить в отложенное исполнение. Сохранить эталонные JS-результаты до правки и сравнить с новым генератором побайтово. Компилировать каждый исходник отдельным процессом: глобальный счётчик `Gensym` не сбрасывается между вызовами.

Использовать существующие общие и JS samples, а также целевые сценарии namespace imports, raw-code и interop. Исторические результаты из source-map change не являются проверкой этого рефакторинга.

## Risks / Trade-offs

- Изменение разделителей или порядка генерации → сравнение с эталоном до рефакторинга, затем `make test`.
- Преждевременная инфраструктура карты → только функция записи и маленькие helpers; расширение для origin относится к `inline-js-source-maps`.

## Migration Plan

Завершить и принять этот change до начала `inline-js-source-maps`. Пользовательские команды и документация языка не меняются. Рефакторинг можно архивировать независимо от карт.
