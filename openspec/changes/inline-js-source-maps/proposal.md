# Proposal

## Why

При падении JS-приложения стек указывает на сгенерированный JavaScript, и пользователю приходится вручную искать соответствующее выражение `.clj`. Нужен стек с исходным файлом, строкой и столбцом через штатный механизм Node.js; основание — проблема #28 и последующее обсуждение, а не предложенный в issue перечень требований.

## What Changes

- `--source-map` включает стандартную Source Map v3, встроенную комментарием в конец JS; ввод через stdin и вывод через stdout сохраняются.
- Имя исходника по умолчанию — `user.clj`. Необязательный `--source-file PATH` переопределяет его; относительный путь разрешается относительно выходного JS, файл по этому пути компилятор не читает.
- Карта содержит исходный текст и привязки пользовательских выражений, включая вызовы после макросов и lowering. Node.js с `--enable-source-maps` переводит позиции стека в `.clj` без перехвата исключений.
- Документация и целевой интеграционный тест описывают и проверяют новый режим. Без карты сохраняется прежний JS-вывод.

## Delivery Stages

Change перепланирован для повторной реализации после отдельно выполняемого отката. Предыдущая реализация служит источником проверенных находок, а не основанием считать новые задачи завершёнными.

1. **Грубая inline-карта:** `--source-map`, имя `user.clj`, исходный текст и привязки к началу верхнеуровневых форм. Пользователь уже может определить проблемную функцию. Внутренний строковый генератор сохраняется.
2. **Настоящее имя исходника:** `--source-file PATH` и корректное разрешение путей, включая пробелы, `#`, `?`, `%`. Пользователь получает ссылку на реальный файл.
3. **Точные позиции выражений:** компактная композиция отложенных фрагментов и привязки вложенных вызовов. Пользователь получает позицию конкретного ошибочного выражения.

Этапы 2 и 3 зависят только от этапа 1 и могут выполняться в любом порядке. Каждый этап включает свои тесты, документацию и `make test`. Грубая точность первого этапа — документированный промежуточный результат; итоговый контракт delta spec требует выполнения всех трёх этапов. Откат кода не входит в обновление этих артефактов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `compiler-targets`: opt-in inline source maps для JS, имя исходника и исходные позиции в стеке Node.js.

## Impact

- `bin/main.ml`, `bin/runner.ml`: параметры режима карты и передача исходного текста генератору.
- `backend_compiler/js.ml` и небольшой модуль кодирования карты: вывод с учётом позиций, сериализация карты. Существующие метаданные AST используются без новой модели происхождения.
- `test/`, `test/dune`: целевые проверки CLI, карты и стека Node.js; `README.md` и английский справочник `skills/y2k-language/SKILL.md` — описание использования.
- Новые внешние зависимости, отдельные `.map`-файлы, пошаговая отладка и production/bundler-интеграции не требуются. Семантика eval, Java и runtime API не меняется.
