## ADDED Requirements

### Requirement: Java target SHALL вызывать функциональный результат выражения

Java target SHALL поддерживать выражение в позиции вызываемой функции, если его результат является функциональным значением языка с арностью текущего вызова от 0 до 4 включительно. Явный `cast` или промежуточный локальный binding SHALL NOT требоваться. Вызываемое выражение SHALL вычисляться ровно один раз на вызов. Для перечисленных ниже сценариев фабрики, callback-цепочки, `get`, `if` и поддерживаемых арностей generated Java SHALL компилироваться и при исполнении возвращать тот же результат, что и eval. В этих сценариях аргументы не создают побочных эффектов, взаимодействующих с вызываемым выражением. Порядок эффектов вызываемого выражения относительно эффектов аргументов этим требованием не определяется. Существующие вызовы непосредственной лямбды и выражения с явным приведением к соответствующему `FnN` SHALL сохранять работоспособность.

#### Scenario: Непосредственный вызов возвращённой функции
- **WHEN** `make-effect` возвращает `(fn [w] w)` и программа исполняет `((make-effect) "ok")`
- **THEN** generated Java компилируется и результат равен `"ok"`

#### Scenario: Цепочка вызовов через параметр
- **WHEN** параметр `onclick` содержит функцию без аргументов, возвращающую `(fn [w] w)`, и программа исполняет `((onclick) "ok")`
- **THEN** generated Java компилируется и результат равен `"ok"`

#### Scenario: Функция из коллекции
- **WHEN** программа исполняет `((get [(fn [w] w)] 0) "ok")`
- **THEN** generated Java компилируется и результат равен `"ok"`

#### Scenario: Функция из условного выражения
- **WHEN** программа исполняет `((if true (fn [w] w) (fn [w] nil)) "ok")`
- **THEN** generated Java компилируется и результат равен `"ok"`

#### Scenario: Поддерживаемые арности
- **WHEN** выражение возвращает функцию арности `N`, где `N` равно 0, 1, 2, 3 или 4, и результат вызывается с `N` аргументами
- **THEN** generated Java компилируется и передаёт значения аргументов соответствующим параметрам по их позиции

#### Scenario: Однократное вычисление фабрики
- **WHEN** фабрика увеличивает счётчик в atom и возвращает функцию, а программа непосредственно вызывает результат фабрики один раз с аргументами без побочных эффектов
- **THEN** счётчик увеличивается ровно на один и возвращённая функция вызывается с переданными аргументами

#### Scenario: Совместимость существующих форм
- **WHEN** программа вызывает непосредственную лямбду, локальное функциональное значение либо результат выражения с явным `cast FnN`, соответствующим числу аргументов
- **THEN** generated Java компилируется и сохраняет результат исполнения этих форм

### Requirement: Java target SHALL применять единое правило FnN к вызываемым выражениям

Функциональный вызов результата выражения SHALL приводить вызываемое значение к `FnN` по числу аргументов без исключений для непосредственных лямбд или явного `(cast TYPE ...)`. Наличие произвольного Java-метода `call` SHALL NOT заменять требование соответствующего `FnN`. Для прямого вызова такого Java-метода SHALL использоваться форма `(.call receiver args...)`, сохраняющая обычное поведение Java interop.

#### Scenario: Явный cast к FnN
- **WHEN** вызывается результат `(cast Fn1 (make-effect))` с одним аргументом и фабрика возвращает функцию одного аргумента
- **THEN** generated Java содержит внешний cast к `Fn1`, компилируется и сохраняет результат вызова

#### Scenario: Явный cast к произвольному Java-интерфейсу
- **WHEN** компилируется `((cast java.util.concurrent.Callable x))`
- **THEN** generated Java приводит вызываемое выражение к `Fn0` перед функциональным вызовом, несмотря на явный Java-тип
- **AND** успешный вызов не гарантируется для объекта, реализующего только `java.util.concurrent.Callable`

#### Scenario: Прямой вызов Java call
- **WHEN** программа исполняет `(.call (cast java.util.concurrent.Callable x))`, где `x` содержит `Callable`, возвращающий `"ok"`
- **THEN** generated Java вызывает Java-метод `call` без дополнительного приведения к `Fn0` и возвращает `"ok"`

### Requirement: Java target SHALL отклонять неподдерживаемую арность вызова выражения

При вызове результата выражения с более чем четырьмя аргументами Java target SHALL завершать генерацию ошибкой, указывающей неподдерживаемую арность, строку и столбец исходной формы вызова.

#### Scenario: Пять аргументов у вызова результата
- **WHEN** компилируется `(defn test [factory] ((factory) 1 2 3 4 5))`
- **THEN** Java-генерация завершается ошибкой, указывающей арность `5` и координаты внешнего вызова, до запуска `javac`
