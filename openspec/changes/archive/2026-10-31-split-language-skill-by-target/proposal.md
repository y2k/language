# Proposal

## Why

Загрузка `y2k-language` приносит весь справочник из 459 строк, включая подробности Java и eval, даже для задачи JavaScript-приложения. Разделение позволит читать общие правила и только справочники targets, затронутых текущей задачей, сохраняя полноту документации.

## What Changes

- Сохранить один скилл `y2k-language`: общие правила языка, библиотеку, CLI, ограничения переносимости и выбор target оставить в `SKILL.md`.
- Вынести подробности targets в `references/js.md`, `references/eval.md` и `references/java.md` внутри каталога скилла; ссылки разрешать относительно этого каталога.
- Предписать загрузку справочника по target конкретной задачи. Дополнительный target читать только при работе с соответствующим кодом: например, eval для исполняемого через eval сборочного скрипта.
- Разнести target-specific сведения из общих разделов, сохранив общие regex-контракты и краткие предупреждения о непереносимости в основной части.
- Обновить правило сопровождения документации в `AGENTS.md`, чтобы оно охватывало основной файл и справочники.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `application-skill`: отдельные файлы справочников вместо обязательных target-подразделов в одном файле; выборочная загрузка и сопровождение комплекта документации.

## Impact

Затрагиваются `skills/y2k-language/SKILL.md`, новые `skills/y2k-language/references/{js,eval,java}.md`, правило в `AGENTS.md` и спецификация `application-skill`. Имя скилла, подключение каталога симлинком, английский язык справочника и семантика языка сохраняются. Компилятор, runtime, тесты языка и зависимости не меняются. JS-default внешнего приложения не становится универсальным правилом скилла или репозитория компилятора.
