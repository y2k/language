# Spec Delta

## ADDED Requirements

### Requirement: Compiler targets SHALL предоставлять filter по истинности языка

JS и Java SHALL предоставлять без пользовательского импорта `(filter pred items)` для одного list/vector. Функция SHALL возвращать исходные элементы с истинным по правилам языка результатом unary-предиката, сохраняя порядок. Nil и false SHALL исключать элемент; 0 и пустая строка SHALL быть истинными. На JS undefined SHALL также считаться ложным результатом предиката.

#### Scenario: Отбор сообщений
- **WHEN** filter получает сообщения с типами `"text"`, `"image"`, `"text"` и предикат `(fn [message] (= (:type message) "text"))`
- **THEN** JS и Java возвращают первое и третье исходные сообщения в том же порядке, как eval

#### Scenario: Истинность и исходные значения
- **WHEN** вычисляется `(filter (fn [x] x) [nil false 0 "" "nil" "false"])`
- **THEN** результат содержит ровно `0`, `""`, `"nil"`, `"false"` с сохранением типов и порядка
- **WHEN** вычисляется `(filter (fn [x] true) [nil false])`
- **THEN** результат содержит исходные nil и false

#### Scenario: Undefined в предикате JS
- **WHEN** JS callback возвращает undefined для элемента
- **THEN** filter исключает этот элемент

### Requirement: Compiler targets SHALL предоставлять keep для результатов без nil

JS и Java SHALL предоставлять без пользовательского импорта `(keep f items)` для одного list/vector. Функция SHALL возвращать результаты unary callback, кроме nil/null, в порядке исходных элементов. False, 0, пустая строка и строка `"nil"` SHALL сохраняться. На JS keep SHALL также исключать undefined, включая результат host-вызова.

#### Scenario: Преобразование карточек
- **WHEN** callback для трёх событий возвращает соответственно карточку A, nil и карточку C
- **THEN** keep возвращает карточки A и C в этом порядке, а не исходные события

#### Scenario: Сохранение значений
- **WHEN** вычисляется `(keep (fn [x] x) [nil false 0 "" "nil" "false"])`
- **THEN** JS и Java возвращают ровно `false`, `0`, `""`, `"nil"`, `"false"` с исходными типами, как eval

#### Scenario: Отсутствующие host-результаты JS
- **WHEN** callback JS keep возвращает последовательно null, undefined, false, 0 и пустую строку
- **THEN** результат содержит ровно false, 0 и пустую строку

### Requirement: Compiler filter и keep SHALL выполнять немедленный упорядоченный обход

Обе операции SHALL вызывать callback ровно один раз на элемент слева направо, передавая только элемент. Именованная функция, лямбда и локальное функциональное значение SHALL поддерживаться, включая вложенный namespace. Сами операции SHALL NOT изменять исходную коллекцию. Пустой вход SHALL давать пустую коллекцию без callback. Ошибка callback SHALL прерывать обход и передаваться наружу без отката эффектов; единый тип и текст host-ошибки не требуются.

#### Scenario: Порядок, namespace и callback
- **WHEN** программа во вложенном namespace передаёт каждой операции `[1 2 3]` и callback, записывающий аргументы в Atom, непосредственно по имени, как лямбду либо через локальный binding
- **THEN** generated JS и Java компилируются, после возврата журнал содержит ровно 1, 2, 3 в этом порядке
- **AND** исходная коллекция по-прежнему содержит 1, 2, 3

#### Scenario: Пустые результаты
- **WHEN** каждая операция получает пустой list/vector и callback с наблюдаемым эффектом
- **THEN** результат является пустой коллекцией, callback не вызывается
- **WHEN** filter отклоняет все элементы либо keep получает nil от каждого callback
- **THEN** результат является пустой коллекцией, не nil

#### Scenario: Ошибка callback
- **WHEN** callback каждой операции записывает эффект и завершается ошибкой на втором элементе из трёх
- **THEN** третий callback не вызывается, ошибка выходит наружу, предыдущие эффекты сохраняются

### Requirement: JavaScript filter и keep SHALL поддерживать плотные host-массивы

JS filter и keep SHALL принимать обычные плотные host-массивы. Callback SHALL получать исходные объекты без преобразования или копирования. Filter SHALL сохранять выбранные исходные объекты, keep SHALL сохранять возвращённые объекты без копирования; операции SHALL NOT изменять входной массив. Sparse arrays, произвольные iterable и изменение состава входа callback не входят в контракт.

#### Scenario: Ссылки и неизменность host-массива
- **WHEN** filter отбирает объекты из плотного JS-массива, а keep возвращает объекты из callback
- **THEN** элементы результатов являются теми же объектами по JS identity, а длина, порядок и элементы исходного массива не изменены самими операциями
