# Spec Delta

## ADDED Requirements

### Requirement: Eval SHALL предоставлять filter по истинности языка

Eval SHALL предоставлять без импорта обычную функцию `(filter pred items)` для одного list/vector. Результат SHALL содержать исходные элементы, для которых unary-предикат вернул истинное по правилам языка значение, в исходном порядке. Только nil и boolean false SHALL исключать элемент.

#### Scenario: Отбор сообщений
- **WHEN** filter получает сообщения с типами `"text"`, `"image"`, `"text"` и предикат `(fn [message] (= (:type message) "text"))`
- **THEN** результат содержит первое и третье исходные сообщения в том же порядке

#### Scenario: Истинность отличается от host truthiness
- **WHEN** вычисляется `(filter (fn [x] x) [nil false 0 "" "nil" "false"])`
- **THEN** результат содержит ровно `0`, `""`, `"nil"`, `"false"` с сохранением типов и порядка
- **WHEN** вычисляется `(filter (fn [x] true) [nil false])`
- **THEN** результат содержит исходные nil и false, а не результаты предиката

### Requirement: Eval SHALL предоставлять keep для результатов без nil

Eval SHALL предоставлять без импорта обычную функцию `(keep f items)` для одного list/vector. Результат SHALL содержать результаты unary callback, кроме отдельного nil, в порядке исходных элементов. Boolean false, число 0, пустая строка и строка `"nil"` SHALL сохраняться.

#### Scenario: Преобразование карточек
- **WHEN** callback для трёх событий возвращает соответственно карточку A, nil и карточку C
- **THEN** keep возвращает карточки A и C в этом порядке, а не исходные события

#### Scenario: Удаляется только nil
- **WHEN** вычисляется `(keep (fn [x] x) [nil false 0 "" "nil" "false"])`
- **THEN** результат содержит ровно `false`, `0`, `""`, `"nil"`, `"false"` с исходными типами

### Requirement: Eval filter и keep SHALL выполнять немедленный упорядоченный обход

Filter и keep SHALL вызывать callback ровно один раз на элемент слева направо до возвращения результата. Callback SHALL получать только элемент; именованная функция, лямбда и локальное функциональное значение SHALL поддерживаться. Сами операции SHALL NOT изменять исходную коллекцию. Пустой вход SHALL давать пустой list без вызова callback. Ошибка callback SHALL прерывать обход и передаваться наружу без отката эффектов.

#### Scenario: Порядок и формы callback
- **WHEN** каждая операция получает `[1 2 3]` и callback, записывающий аргументы в Atom, непосредственно по имени, как лямбду либо через локальный binding
- **THEN** после возврата журнал содержит ровно 1, 2, 3 в этом порядке
- **AND** исходная коллекция по-прежнему содержит 1, 2, 3

#### Scenario: Пустые результаты
- **WHEN** каждая операция получает пустой list/vector и callback с наблюдаемым эффектом
- **THEN** результат является пустым list, callback не вызывается
- **WHEN** filter отклоняет все элементы либо keep получает nil от каждого вызова
- **THEN** результат является пустым list, не nil

#### Scenario: Ошибка callback
- **WHEN** callback каждой операции записывает эффект и вызывает `(assert false)` на втором элементе из трёх
- **THEN** наружу передаётся `Eval_error` с `assertion failed`, третий callback не вызывается, предыдущие эффекты сохраняются

### Requirement: Eval SHALL проверять аргументы filter и keep по образцу map

Обе функции SHALL принимать ровно два аргумента: callable и list/vector. Неверная арность, не-callable callback или иной тип коллекции SHALL давать Eval_error с именем операции и ожидаемыми аргументами. Callable SHALL проверяться даже на пустом входе; арность параметров допустимого callback SHALL проверяться только при фактическом вызове.

#### Scenario: Неверные аргументы
- **WHEN** filter либо keep вызывается без аргументов, только с callback, с лишним третьим аргументом, с числом вместо callback или с nil/map вместо коллекции
- **THEN** возникает Eval_error соответствующей операции, включая не-callable callback при пустой коллекции

#### Scenario: Арность callback
- **WHEN** filter либо keep получает `(fn [a b] a)` и пустой list
- **THEN** callback не вызывается, возвращается пустой list
- **WHEN** та же функция передана с непустым list
- **THEN** возникает ошибка арности callback при вызове
