## Context

После desugaring вызов `(f x)` представлен обычным списком. Eval вычисляет голову списка, а JavaScript generator компилирует её как выражение, поэтому локальный параметр `f` можно вызвать. Java generator отдельно обрабатывает атомарную голову как прямой Java method call и не проверяет `ctx.locals`, хотя локальные значения имеют тип `Object`, а runtime уже предоставляет интерфейсы `Fn0`-`Fn4` с методом `call`.

## Goals / Non-Goals

**Goals:**

- Генерировать компилируемый Java-код для вызова лямбды, переданной через параметр функции.
- Сохранять лексический приоритет локального символа над одноимённой top-level или runtime-функцией.
- Подтвердить одинаковый результат на eval, JavaScript и Java targets общим sample test.

**Non-Goals:**

- Добавлять новые runtime-интерфейсы или расширять поддерживаемую Java-арность выше четырёх аргументов.
- Менять parser, desugaring, lowering, eval или JavaScript generator.
- Добавлять поддержку вложенного `def`.

## Decisions

- В ветке Java generic call атомарная голова, присутствующая в `ctx.locals`, будет приведена к `FnN`, где `N` равно числу аргументов, и вызвана через `.call(...)`. Это использует существующие `fn_interface` и runtime-контракт вместо нового dispatch helper.
- Нелокальные атомарные головы сохранят прямой вызов через `compile_qualified_name`, чтобы не менять генерацию runtime, top-level и qualified calls.
- Проверка будет добавлена как один общий файл в `test/samples/`: существующий harness автоматически запускает его на eval, JavaScript и Java и для Java выполняет реальную компиляцию через `javac`. Параметр с именем runtime-функции одновременно проверит lexical shadowing.

Рассматривался вызов всех атомарных голов через `call_fn`, но он потребовал бы превращать runtime и qualified methods в функциональные значения и расширил бы изменение без необходимости.

## Risks / Trade-offs

- [Приведение локального нефункционального значения завершится Java `ClassCastException`] → это соответствует ошибке вызова нефункционального значения и не маскирует дефект генерации.
- [Вызов локальной функции остаётся ограничен арностью `Fn0`-`Fn4`] → используется существующее ограничение Java backend и единая проверка `fn_interface`.
