# Spec Delta

## ADDED Requirements

### Requirement: Eval SHALL предоставлять двухаргументный sort-by

Eval SHALL предоставлять без импорта обычную функцию `(sort-by keyfn coll)` для unary-функции и list/vector. Результат SHALL содержать исходные элементы по возрастанию вычисленного ключа. Поддерживаются именованная функция, лямбда и локальное функциональное значение. Другие арности, пользовательский компаратор, map и nil вместо коллекции не входят в API.

#### Scenario: Сортировка событий
- **WHEN** sort-by получает события A, B, C с приоритетами 20, 3, 10 и функцию извлечения приоритета
- **THEN** результат содержит события B, C, A

#### Scenario: Формы функции ключа
- **WHEN** одна функция извлечения ключа передана непосредственно по имени, через локальный binding либо как лямбда
- **THEN** каждый вызов возвращает одинаковый порядок элементов

### Requirement: Eval sort-by SHALL сравнивать числовые ключи по значению

Для числовых ключей sort-by SHALL поддерживать целые и конечные binary64, включая их смесь, с порядком по числовому значению без epsilon. Численно равные ключи SHALL считаться равными для сортировки, включая целое и binary64 того же значения и оба знака нуля. Сравнение SHALL NOT округлять большое целое в binary64 с потерей порядка. Non-finite значения вне контракта.

#### Scenario: Смешанные числа
- **WHEN** ключи элементов равны 10, -2, 1.5, 1, 0.25
- **THEN** результат упорядочен по ключам -2, 0.25, 1, 1.5, 10

#### Scenario: Численно равные ключи
- **WHEN** элементы A, B, C, D, E имеют ключи 1, 1.0, 0, -0.0, 0.0
- **THEN** порядок результата — C, D, E, A, B

#### Scenario: Большое целое и binary64
- **WHEN** на 64-bit eval элементы A и B имеют ключи 9007199254740993 и 9007199254740992.0
- **THEN** B предшествует A, ключи не считаются равными из-за округления

### Requirement: Eval sort-by SHALL сравнивать строки без locale

Строковые runtime-ключи SHALL сравниваться лексикографически, с учётом регистра и без locale. Для ASCII порядок SHALL совпадать с JS/Java; префикс предшествует более длинной строке. Остальной Unicode SHALL иметь документированный target-specific порядок. Все ключи одного вызова — либо строки, либо числа; nil, boolean, составные ключи и смесь строк с числами вне контракта.

#### Scenario: ASCII и префиксы
- **WHEN** ключи равны "a", "2", "A", "10", "", "aa"
- **THEN** порядок ключей результата — "", "10", "2", "A", "a", "aa"

### Requirement: Eval sort-by SHALL сохранять стабильность и входные элементы

Sort-by SHALL сохранять исходный порядок элементов с равными ключами и SHALL NOT изменять входную коллекцию или копировать её элементы. Результат SHALL быть list, включая пустой вход. Гарантии относятся к действиям самой операции; изменение входа или элементов из callback вне контракта.

#### Scenario: Равные ключи и исходный порядок
- **WHEN** события A, B, C имеют ключи 20, 3, 20
- **THEN** результат содержит B, A, C, а исходная коллекция по-прежнему содержит A, B, C

#### Scenario: Пустой вход
- **WHEN** sort-by получает пустой list/vector
- **THEN** результат является пустым list, не nil

### Requirement: Eval sort-by SHALL вычислять ключи однократно слева направо

Sort-by SHALL немедленно вызвать keyfn ровно один раз для каждого элемента в исходном порядке с единственным аргументом — этим элементом. Пустой вход SHALL NOT вызывать keyfn; одноэлементный SHALL вызывать её один раз. Ошибка keyfn SHALL прерывать обход и передаваться наружу без замены и без отката предыдущих эффектов.

#### Scenario: Журнал вычисления ключей
- **WHEN** keyfn записывает ID в Atom и возвращает ключ для входных A, B, C
- **THEN** после sort-by журнал содержит ровно A, B, C независимо от порядка результата

#### Scenario: Ноль и один элемент
- **WHEN** sort-by последовательно получает пустую и одноэлементную коллекции с keyfn, увеличивающей счётчик
- **THEN** счётчик после первого вызова равен 0, после второго — 1

#### Scenario: Ошибка callback
- **WHEN** keyfn записывает эффект и завершается ошибкой на втором элементе из трёх
- **THEN** третий keyfn не вызывается, исходная ошибка выходит наружу, предыдущие эффекты остаются
