## Why

Агенту OpenCode в проектах приложений нужен переносимый справочник по реально поддерживаемому Y2K Language, чтобы не подменять его возможностями Clojure. Существующий README не содержит полного справочника и уже отстаёт от реализации, например в ограничении арностей Java function values.

## What Changes

- Добавить англоязычный скилл `y2k-language` для написания и исправления приложений, хранящийся в `skills/y2k-language/SKILL.md` и подключаемый симлинком каталога в `.opencode/skills/y2k-language` проекта приложения.
- Описать все пользовательские встроенные формы и кроссплатформенную стандартную библиотеку: сигнатуры, семантику, ограничения и короткие примеры.
- Вынести target-specific возможности в отдельный раздел с подразделами `eval`, `js`, `java`.
- Описать запуск через `ly2k` из `$PATH`, учитывая автоматическую доставку runtime-файлов системой сборки приложения.
- Добавить ссылки на репозиторий и issues и указания по минимальному воспроизводимому примеру.
- Закрепить обновление скилла при изменении пользовательских возможностей языка; справочник описывает текущую реализацию без отдельных версий.

## Capabilities

### New Capabilities

- `application-skill`: обнаруживаемый OpenCode переносимый скилл с инструкциями для разработки приложений на Y2K Language и правилами актуальности его справочника.

### Modified Capabilities

Нет. Поведение языка и targets не меняется.

## Impact

- Новый `skills/y2k-language/SKILL.md`; правило актуализации в корневом `AGENTS.md`.
- Подключение в проектах-потребителях через стандартный каталог скиллов OpenCode, без новых зависимостей или настроек `opencode.json`.
- Реализация, runtime и существующие тесты служат источниками проверки содержания. Изменения компилятора и системы сборки не требуются.
