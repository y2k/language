# Proposal

## Why

Существующий interop позволяет вызывать host API, но не вставлять произвольные объявления и инструкции JavaScript или Java. Нужен явный escape hatch для кода, который пользователь хочет сохранить без преобразований генератора.

## What Changes

- Добавить общую специальную форму `(raw-code "text")` для JS и Java: вставлять декодированное содержимое строкового литерала без экранирования, munging, обёрток, `return` и дополнительного `;`.
- Разрешить непосредственную top-level вставку: в JS module, в Java — внутри helper class на месте формы, не перед классом.
- Разрешить вставку инструкций внутри функции перед обычным результирующим выражением. Value positions и последнее выражение тела не поддерживаются; диагностика исходных позиций не гарантируется.
- По согласованию в ходе apply исправить существующий JS defect: lowered statement-блок отброшенной ветки `if` внутри `let` не должен становиться вызовом `let_STAR_`. Это необходимо для принятого контракта условной вставки; добавить общую регрессию без raw-code.
- Проверять арность и исходный строковый литерал при извлечении payload; не вводить обход AST для проверки позиций до lowering.
- В eval явно отклонять достигнутую форму, не вычисляя аргументы.
- **BREAKING**: имя raw-code в head списка становится специальной формой вместо обычного пользовательского вызова.
- Обновить английский справочник и добавить target-specific fixtures и целевые проверки генерации/диагностики.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `compiler-targets`: контракт raw-code для JS/Java, допустимые позиции и явное отклонение в eval.

## Impact

- `backend_compiler/lowering_expression_to_statement.ml`: обычное lowering без дополнительной проверки позиций.
- `backend_compiler/js.ml`, `backend_compiler/java.ml`: отдельные пути генерации raw-code без стандартных суффиксов.
- `frontend/`: проверка исходного литерала до превращения keywords в строки; без новой системы макросов или reader syntax.
- `backend_eval/eval.ml`: ошибка неподдерживаемой формы.
- `test/`, `test/dune`, `skills/y2k-language/SKILL.md`: проверки и документация.
- Без новых зависимостей или изменений runtime-файлов. Текст относится только к выбранному target, не переводится между JS и Java и не является sandboxed-кодом.
